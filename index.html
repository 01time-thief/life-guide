档案毕业当年必须本人到场省市自定有窗口期
展开步骤 ▾

下一步该办什么

  1. 1
    确认接收单位或人才中心是否具备档案保管资质产物 · 接收函或调档函
  2. 2
    由学校就业中心发起转递（机要或 EMS）产物 · 转递单号
  3. 3
    到档后在省级人社或人才中心查到档状态产物 · 到档确认

执行难点与过法（真正卡人的地方）

  • 根本不知道档案在哪→ 三步查：学校档案馆/就业中心 → 户籍地公共就业和人才服务机构 → 打 12333。毕业两年内多数还在学校
  • 单位没有档案保管权限却说要接收→ 让单位出委托存档函，由当地人才服务机构接收，别把档案寄到单位
  • 档案被自己拿在手里→ 尽快退回原存档机构或转户籍地人才中心；各地对自持期限规定不同，拖久了会被拒收
  • 调档函抬头写错→ 抬头必须是档案实际接收单位全称，写完先让接收方确认再寄

常见失败（最容易踩的坑）

  • 档案自己拿着走 → 变成死档，多地不认
  • 转递去向填错 → 退回重寄，拖 1~3 个月
  • 只寄档案不寄转递通知单 → 对方拒收

就业签约与毕业去向登记样例待判定

就业毕业前3月可代办省市自定有窗口期
展开步骤 ▾

下一步该办什么

  1. 1
    确认接收单位有没有接收资质、能不能存档产物 · 明确的接收单位
  2. 2
    签三方协议或劳动合同，学校就业中心盖章产物 · 已签三方协议或劳动合同
  3. 3
    按学校要求完成毕业去向登记产物 · 就业登记完成回执

执行难点与过法（真正卡人的地方）

  • 三方协议丢了或想换单位→ 找学校就业中心补办或开解约函；多数学校每年只给有限次解约，先问清次数再签
  • 单位只催签三方、迟迟不给劳动合同→ 三方是意向约定，劳动关系以劳动合同为准；《劳动合同法》要求用工之日起一个月内订立书面合同，过了这个点可以书面催告
  • 实习期被当试用期用→ 在校实习不属于劳动关系，试用期只存在于劳动合同里；入职即要求签合同、看试用期条款

常见失败（最容易踩的坑）

  • 先签了不接收档案的单位 → 档案无处可去，只能回原籍
  • 错过学校集中办理窗口 → 之后要自己跑省市就业中心
  • 把三方协议当成劳动合同 → 以为工资社保已谈定，实际这些只在劳动合同里

口径提醒（文件性质决定效力，先看清再签）

  • 三方协议属于「就业意向」层面的约定，劳动合同才是确立劳动关系的书面凭证；两者的法律效力、能装进去的条款、违约后果都不一样，不是同一张纸的两个名字。
  • 实习协议、劳务合同、劳务派遣是另外三种形态，签约主体与权利义务各不相同；签字前先看清文件标题、甲方是谁、盖的是什么章。
  • 试用期、工资、社保这些只在劳动合同里约定；三方协议里通常没有，签了也不代表已经谈定。
  • 涉及违约金、服务期、竞业限制的条款，以书面文本为准；没看懂就先别签，把文件带回学校就业中心或打 12333 问清口径。
  • 本站只给办理顺序和官方入口，不提供法律意见；具体处理以官方解释和受理机构的口径为准。

  2. 2
    出分后在专题网站查分，并核对是否进入首批面试名单产物 · 是否进面的结论

  1. 1
    到指定医院参加体检，按通用标准执行，公安等岗位另按特殊标准产物 · 体检结论
  2. 2
    配合招录机关考察，提交档案、现实表现证明等考察材料产物 · 考察材料

  • 档案还在学校或异地且材料不全 → 考察拖慢，影响按期报到

  1. 1
    在教务系统打印成绩单，逐项核对必修学分、限选学分、实践学分是否达标产物 · 学分自查表
  2. 2

档案被退回 / 人才中心不收

展开补救 ▾
档案被退回学校人才中心说格式不对档案在手里拿着转递单没人签收档案不知道在哪

最可能的原因

  • 档案走的是自己携带或个人快递，接收机构不认（正规是机要或专用 EMS，且必须密封）
  • 接收机构选错：非户籍地、非就业地的人才机构没有接收义务
  • 缺《档案转递通知单》或报到信息与系统中不一致

三步补救

  1. 1先查档案现在在哪：联系毕业学校档案室或原接收机构，要一个明确的「现存位置 + 状态」回复
  2. 2找回密封原状：如果已拆封，请学校或原单位重新审核密封并出具情况说明，别自己贴封条
  3. 3重走机要或专用 EMS：让接收机构出具接收函，学校按函件走机要通信转递，全程留快递单号

社保断缴 / 转移没跟上

展开补救 ▾
社保断了几个月转移接续没到账新单位说查不到我的社保灵活就业忘了缴视同缴费年限不认

最可能的原因

  • 换工作空档期没有以灵活就业身份续缴
  • 跨省转移只申请了新参保地，原参保地没有办转出
  • 单位申报了但未实际缴费，系统显示「已申报未到账」

三步补救

  1. 1打 12333 或登录参保地社保 App，查三件事：原参保地状态、是否已办转出、新参保地是否已接收
  2. 2缺哪一步补哪一步：先让原参保地办转出（要《参保缴费凭证》），再让新参保地办接收
  3. 3断缴当年能补的尽快补（是否允许补缴、补缴是否影响待遇，以当地社保经办机构口径为准）

  • 专业名称与职位表要求不一致（职位表按专业目录，不按你毕业证上的写法）
  • 学历、学位、应届身份填写与报名系统校验不匹配
  • 基层工作经历、服务期未按要求提供佐证材料

三步补救

  1. 1先把招考公告附件里的「专业目录 / 报考指南」找出来，对照自己专业的确切归类，不要按感觉判断
  2. 2在报名系统里看退回原因原文，按原因改材料；不确定就打电话问招录机关（公告里有电话）
  3. 3在规定改报时间内改报其他职位或补充材料，过期一般不再受理

展开补救 ▾
异地住院没报销医保说没备案自费结算了还能不能补门诊费用不认

最可能的原因

  • 跨省异地就医没有做备案，医院按自费结算
  • 备案类型选错（长期居住 vs 临时外出 vs 转诊转院）
  • 报销材料不全（发票、费用清单、出院小结、社保卡缺一）

三步补救

  1. 1先在国家医保服务平台查备案状态与备案类型，类型不对就改
  2. 2已自费结算的，回参保地问「手工报销」窗口与时限（各地时限不同，越早越好）
  3. 3备齐材料：发票原件、费用清单、出院小结、病历、社保卡，按参保地清单提交

展开补救 ▾
单位说我不是应届交了社保就不算应届了吗择业期怎么算三方签了算不算就业

最可能的原因

  • 应届身份在校招、考公、落户三套口径里定义不同，不能混用
  • 缴纳职工社保、签劳动合同会影响部分口径下的「未就业」认定
  • 择业期（一般两年）以毕业证时间为起点，各地细则不同

三步补救

  1. 1先确认你要用的口径：校招问学校就业中心，考公看当年公告的报考指南，落户看当地公安与人才政策
  2. 2准备好三份材料：毕业证学位证、社保缴费记录、档案存放证明，随时可举证
  3. 3拿不准就别先签劳动合同或缴社保，先问清目标口径再决定

这是什么站，不是什么站

一句话定位：how-to-live / work 的执行端导航。你已经知道这事该办，缺的是「去哪办、按什么顺序办、带什么、会被卡在哪」——这里只补这一段。

它做什么

  • 把事项拆成动作：每张卡片从「确认接收方」到「拿到凭证」分步写，每步标注产物（带验证码的报告 PDF、转递单号、备案回执），不写「去申请」这种空话。
  • 把顺序写成依赖：卡片上的「先办 · ××」就是前置事项，画成有向图后可以按「现在能办什么」筛选。
  • 把卡点写成过法：执行难点一栏写的是窗口、系统、材料上真正卡人的那一刻，以及绕过去的做法。
  • 入口实测：每条官方入口都由脚本请求过，记录状态码 / 落地 URL / 落地标题 / 核实日期；打不开的宁可不给链接。

它不做什么

  • 不做政策原文库与解读，一律外链官方页面；政策以官方现行文件为准。
  • 不给法律意见、医疗建议、投资建议，也不替你选城市、选岗位、选路径——决策留给当事人。

它和网址大全的区别

  • 事项之间有依赖边：办档案转递之前得先有接收单位，所以卡片上会写「先办 · 就业签约」。
  • 每条事项有产物：不是「去申请」，而是「拿到带验证码的报告 PDF」「拿到转递单号」。
  • 每条事项有常见失败：这是本站最值钱的部分，写的是别人已经踩过的坑。

入口怎么核实的

  • 脚本批量请求每个候选地址，记录 状态码 / 落地 URL / 落地标题 / 核实日期 四项。
  • 标题对不上预期的判「待确认」，状态码 4xx/5xx 或域名不存在的判「待核实」——宁可不给链接，也不给坏链接。
  • 部分政务站还在用旧 TLS（浏览器能开、脚本被拒），这类单独标注，需要你在浏览器里再确认一次。
  • 核实日期超过 12 个月，页面会提示「可能已变化，以官方为准」。

明确不做

  • 不做政策原文镜像（版权 + 时效），一律外链官方。
  • 不给法律意见或医疗建议，只给「去哪办、怎么办、找谁问」。
  • 市级事项只做一线四城 + 河南重点城市；其他城市请在页面上走省级入口。
