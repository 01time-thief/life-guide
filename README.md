# 人生执行导航站 · how-to-live

> 毕业前后要办的事，按「现在能办什么」排：每条都有分步、产物、常见失败、执行难点与**实测过的官方入口**。

- 打开就能用：**单文件静态页**，零外链、零追踪、不需要登录
- 内容核实日期：2026-10-21/22｜数据源 90 个（79 个实测可用）
- 页面内容指纹：**155b4b2b7088**（页脚可见，与 `SHA256SUMS.txt` 对照，被改过就不一致）

## 里面有什么

| 模块 | 说明 |
|---|---|
| 事项清单 | 40 条可执行事项：分步 + 产物 + 常见失败 + 卡点过法；可按阶段/板块/渠道/地区/时限筛选 |
| 地区入口 | 47 张省市入口卡（省级 31 / 市级 16），标明「已填实 / 模板」，一省通办优先 |
| 考试日历 | 37 场考试（公务员/事业单位/教师/医疗/基层/军队/国企/资格证），省份 + 类型两级筛选 |
| 我卡住了 | 6 类卡点按症状反查：档案被退回、社保断缴、审核不过、报销被拒、应届身份、错过窗口期 |
| 数据源 | 每个入口的状态码、落地标题、判定结果都可查，没实测通过的不给链接 |

用户侧只有两个本地能力：**收藏** 与 **记一笔**（都存在你自己浏览器里，不上传）。本站没有后台、没有登录、没有编辑入口。

## 用之前知道三件事

1. 这是**办事路径指北**，不是法律意见；涉及合同效力、责任认定的，请以官方解释为准。
2. 政策一年一变：页面每条都标了核实日期，过期信息欢迎提 Issue。
3. 官方链接全部脚本实测（状态码 + 落地标题 + 真浏览器渲染），打不开的不会硬给链接。

## 反馈

- 发现某条过期 / 官方链接挂了 / 说法有误 → 开 Issue（三行说清：哪一条、什么问题、你在哪个省）
- 内容授权：见 `CONTENT-POLICY.md`（允许学习引用，整站镜像与商用需授权）

## 本地构建

本站由脚本生成，源码与数据在作者本地。公开仓库只放构建产物：

```
index.html  robots.txt  _headers  netlify.toml
CONTENT-POLICY.md  PUBLISH.md  README.md  SHA256SUMS.txt  .well-known/security.txt
```

校验方式：`SHA256SUMS.txt` 里每个文件的 sha256 + 页面内容指纹，可自行核对。
